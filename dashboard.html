Calculation notes

What this model is doing

The model combines BLS occupation wages, BEA regional price levels, Census ACS housing context, BLS CPI-U category changes, and documented household assumptions. Observed source fields are kept separate from the modeled budget choices so each result can be read as a transparent affordability scenario.

Affordability ratioTake-home income ÷ modeled monthly budget
Monthly leftoverTake-home income − modeled monthly budget
Same-home testBedroom-specific rent changes by state while bathroom count and square footage define the standardized home profile

This is a transparent scenario estimate, not financial advice. Sources, transformations, dropped rows, and assumptions are documented in the project data contract.
